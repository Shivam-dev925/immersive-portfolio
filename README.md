# Immersive Portfolio

An interactive portfolio for Shivam Choudhary, built as two synchronized layers:

- a fixed Three.js canvas for spatial motion and project objects;
- an accessible React/DOM layer for content, navigation, and interactions.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

The Vite build uses relative asset paths so it can be deployed to GitHub Pages.
